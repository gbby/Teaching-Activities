# Teaching-Activities
This repository contains basic instructionals and resources for general data visualization, geospatial visualization, and AR/VR teaching activities carried out in conjunction with the following undergraduate and graduate courses at Ontario Tech University: 3D Methods for GIS, Visualization and Data Storytelling, Advanced Business Intelligence, and Communicating with Data.

While some of the tutorials are general enough to be used across a variety of different visualization courses, others are geared toward specific courses.
